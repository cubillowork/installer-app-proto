# Installer App × Partner Portal — prototype

Clickable prototype of the SunPower Installer App with the Partner Portal features, organised with a **view switcher** in the header: Installs · Academy · Partner program · Buy products.

Live: **https://cubillowork.github.io/installer-app-proto/**

Built with **[Flux DS](https://github.com/cubillowork/flux-ds)** (`flux-ds` v0.1.0) — every colour, size and text style comes from Flux tokens.

## Screens

- [ ] Installs (home) — systems overview, alerts, pending warranties, New installation
- [ ] View switcher
- [ ] Academy — continue learning, training videos, live training
- [ ] Partner program — tier, benefits, news, leads, marketing
- [ ] Buy products — catalogue, cart, requests

## Run locally

```bash
npm install
npm run dev
```

## Update Flux

Change the tag in `package.json` (`github:cubillowork/flux-ds#v0.2.0`) and run `npm install`.
